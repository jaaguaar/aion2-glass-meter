# План: aion2-glass-meter

Мета: прозорий локальний DPS-метр для Aion 2 на C#/.NET, яким не страшно поділитися з друзями.

Принципи:
- **Пасивно.** Лише читаємо копію мережевого трафіку. Не чіпаємо процес гри, її пам'ять і файли.
- **Локально.** Дані бою нікуди не відправляються. Єдиний мережевий запит — опційний запит профілю персонажа на plaync.
- **Прозоро.** Відкритий код. Збирає GitHub Actions, а не чийсь ПК. Кожен реліз має контрольні суми та атестацію збірки.
- **Мінімум залежностей.** Без Npcap і без інсталятора.

---

## Чому всі використовують Npcap

Причини здебільшого технічні й історичні, а не зловмисні. Але є кілька речей, які нам справді треба врахувати.

| Npcap дає | Вбудовані засоби Windows | Що це означає для нас |
|---|---|---|
| Фільтр BPF у ядрі: у програму потрапляє лише потрібний порт | Raw socket отримує **весь** IP-трафік інтерфейсу, фільтруємо самі | Більше навантаження на CPU. Для одного гравця, імовірно, непомітно; перевіримо на спайку |
| Бачить вхідні й вихідні пакети на будь-якому адаптері | Raw socket прив'язаний до IP одного інтерфейсу. Вихідні пакети на частині конфігурацій можуть не потрапляти | Для урону потрібні лише **вхідні** (від сервера), тож це, імовірно, не критично |
| **Loopback-адаптер** (трафік усередині ПК) | Raw socket loopback не бачить | ⚠️ **ExitLag, ping reducer, частина VPN** пропускають трафік гри через loopback або свій тунель. Тоді raw socket бачить лише зашифрований тунель. Головний ризик нашого підходу |
| Запис у `.pcap`, відкривається у Wireshark | Немає | Пишемо свій простий формат дампу (лише порт гри) для налагодження |
| Зрілі бібліотеки (SharpPcap, libpcap), той самий код на Linux/macOS | Мало прикладів, Windows-only | Це лише незручність для розробника |
| — | Pktmon/ETW: вбудований, бачить усі адаптери, зокрема віртуальні | Запасний варіант, якщо raw socket не впорається. Складніший, потребує Windows 10 2004+ |

Чому автори так роблять:
- Npcap у них уже стоїть, бо вони користуються Wireshark.
- Це стандарт, що працює всюди, зокрема з ExitLag.
- Ліцензія Npcap забороняє вкладати його інсталятор у свою програму без платної OEM-ліцензії. Тому користувача просять поставити його окремо.

Злого наміру в самому виборі Npcap нема. Проблема в довірі до конкретної програми: A2Tools, наприклад, вивантажує частину пакетів на свій сервер.

**Висновок:** тримаємо захоплення за інтерфейсом `IPacketSource`. Перша реалізація — raw socket. Якщо на спайку виявиться, що не працює з ExitLag/VPN або губить пакети, додаємо Pktmon/ETW. Npcap лишаємо як опцію для тих, у кого він уже стоїть.

## Як запускати

- Один файл `aion2-glass-meter.exe`: self-contained .NET 10, нічого не встановлюється.
- **Потрібні права адміністратора.** Без них Windows не дає слухати сирий трафік. У маніфесті `requireAdministrator`, тож Windows сама попросить підтвердження (UAC).
- SmartScreen попередить про «невідомого видавця», бо підпис коду коштує грошей. Для друзів описуємо в README, як перевірити файл (див. «Прозорість»).
- Порядок роботи: запустити гру → запустити метр → він сам знаходить інтерфейс і порт гри за бойовою сигнатурою.

### Налаштування

Файл `settings.json` поруч з exe. Якщо файлу немає, працюють значення за замовчуванням.

```jsonc
{
  "capture": {
    "source": "auto",          // auto | rawsocket | pktmon
    "interface": "auto",       // або IP конкретного адаптера
    "gamePort": "auto"         // або число, якщо автовизначення не спрацювало
  },
  "output": {
    "folder": "%USERPROFILE%\\Documents\\aion2-glass-meter",
    "fightIdleSeconds": 5,     // скільки секунд без урону = кінець бою
    "rawDump": false           // запис сирих пакетів порту гри (лише для налагодження)
  },
  "character": {
    "region": "eu",
    "lookup": false            // запитувати профіль на plaync (вимкнено за замовчуванням)
  },
  "opcodes": "opcodes.json"    // таблиця опкодів; оновлюється без перезбирання після патчів
}
```

## Прозорість і збірка

- **Публічний репозиторій** на GitHub.
- **GitHub Actions:**
  - `ci.yml`: збірка й тести на кожен push і PR.
  - `release.yml`: на тег `v*` збирає exe, рахує SHA-256, робить **build provenance attestation** і публікує GitHub Release.
  - Друг може перевірити, що exe зібраний саме з цього коду: `gh attestation verify aion2-glass-meter.exe --repo jaaguaar/aion2-glass-meter`.
- Dependabot для NuGet і Actions. Мінімум пакетів: LZ4, тести.
- У README розділ **«Що програма робить і чого не робить»**: які мережеві з'єднання відкриває (лише plaync, якщо увімкнено), куди пише файли, що не чіпає гру.

- [ ] CI-скелет.

### 1. Спайк захоплення (консоль)
- [ ] Raw socket `SIO_RCVALL`: чи бачимо TCP-потік гри; вхідні й вихідні окремо.
- [ ] Перевірка з ExitLag/VPN, якщо ви чи друзі ними користуєтесь.
- [ ] Автовизначення порту гри.
- [ ] Якщо щось не так — Pktmon/ETW.

**Результат:** у консолі видно пакети гри, є файл дампу.

### 2. Парсер
- [ ] Збирання TCP-потоку (порядок, повтори, пропуски).
- [ ] Фреймінг: varint, пропуск TLS-записів, LZ4-бандли.
- [ ] `04 38` (урон), `05 38` (DoT), спавни для імен, склад групи.
- [ ] Юніт-тести на записаних дампах.

### 3. Бета (без інтерфейсу)
- [ ] Визначення початку й кінця бою.
- [ ] Збереження в файли:
  - `fights/2026-11-20_21-04-13.json` — повний бій: учасники, скіли, удари, крити, DoT.
  - `fights/summary.csv` — по рядку на бій і гравця: тривалість, урон, DPS, топ-скіл.
- [ ] Консоль показує DPS у реальному часі.
- [ ] **Тест 1:** опудало, порівняння з офіційним метром (`Ctrl+X`): сумарний урон, DPS, розбивка по скілах.
- [ ] **Тест 2:** з друзями. Чи бачимо урон інших гравців групи і їхні імена.

### 4. Оверлей
- [ ] WPF-вікно: прозоре, поверх гри, кліки проходять крізь нього, перетягується за ручку.
- [ ] Гарячі клавіші: показати/сховати, скинути, закріпити.
- [ ] Список гравців з DPS, розгортання по скілах.

- [ ] Історія боїв: той самий бос, різні дати чи білди.

## Порівняння з офіційним метром

Чи зберігає офіційний метр історію на диск, поки **невідомо**: гра не встановлена на цьому ПК, і в джерелах про експорт нічого немає. Імовірніше, дані живуть лише в пам'яті клієнта.

Як перевірити на вашому ігровому ПК: після бою з увімкненим `Ctrl+X` знайти файли, змінені за останні 10 хвилин.

```powershell
$since = (Get-Date).AddMinutes(-10)
$roots = @("$env:LOCALAPPDATA", "$env:APPDATA", "$env:USERPROFILE\Documents", "<папка гри>")
$roots | ForEach-Object { Get-ChildItem $_ -Recurse -File -ErrorAction SilentlyContinue |
  Where-Object LastWriteTime -gt $since } | Select-Object LastWriteTime, Length, FullName
```

Якщо файл знайдеться — розбираємо формат і робимо такий самий звіт для автоматичного порівняння. Якщо ні — порівнюємо вручну: скріншот офіційного метра плюс наш `summary.csv` за той самий бій.
